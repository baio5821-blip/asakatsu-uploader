プライバシーポリシー

最終更新日: 2026年11月16日

取得する情報

本ツールは、Google の OAuth 認証を通じて、YouTube Data API を使って作者自身のチャンネルへ動画・サムネイルをアップロードし、再生リストを管理する権限のみを取得します。

情報の利用と保存

取得した認証情報（リフレッシュトークン）は、作者のパソコン内にのみ保存し、作者の動画をアップロードする目的以外には使用しません。外部のサーバーには送信・保存しません。

第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。

アクセスの取り消し

Google アカウントのサードパーティ アクセス設定から、いつでも本ツールの権限を取り消せます。
